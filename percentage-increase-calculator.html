How to Calculate Percentage Increase

To calculate percentage increase, subtract the original value from the new value, then divide that difference by the original value, and multiply by 100.

Percentage Increase = ((New Value - Original Value) / Original Value) × 100

This formula is useful when you want to calculate percentage increase in price, salary, revenue, marks, or any other value.

Worked Example

Suppose a product price increases from 100 to 125.

Difference = 125 - 100 = 25
Percentage Increase = (25 / 100) × 100 = 25%

So, the percentage increase is 25%.

Percentage Increase vs Percentage Difference

Many people search for both percentage increase calculator and percentage difference calculator, but they are not always the same thing.

Concept Meaning
Percentage Increase Shows how much a value has increased compared to the original value.
Percentage Difference Compares two values to show how different they are, usually without focusing on growth from a starting point.

Frequently Asked Questions

How do I calculate percentage increase between two numbers?

Subtract the original number from the new number, divide by the original number, and multiply by 100.

What is the percentage increase formula?

((New Value - Original Value) / Original Value) × 100

Can this calculator work out percentage decrease too?

This page is focused on increase, but the same method can also show when a value has gone down. You can later create a separate percentage decrease calculator page.

What happens if the original value is zero?

You cannot divide by zero, so percentage increase cannot be calculated from an original value of zero using the standard formula.
